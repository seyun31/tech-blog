## 들어가며

개발자로서 자신만의 블로그를 가지는 것은 여러 장점이 있습니다. 학습한 내용을 정리하고, 포트폴리오로 활용하며, 다른 개발자들과 지식을 공유할 수 있습니다.

이 글에서는 **Next.js 15**와 **MDX**를 사용하여 개인 블로그를 만드는 과정을 소개합니다.

## 기술 스택

이 블로그는 다음 기술 스택으로 구성되어 있습니다:

- **Next.js 15** - App Router 기반 React 프레임워크
- **TypeScript** - 타입 안전한 개발
- **Tailwind CSS v4** - 유틸리티 퍼스트 CSS
- **MDX** - Markdown에 JSX를 결합한 콘텐츠 포맷
- **next-themes** - 다크모드 지원

## MDX란?

MDX는 Markdown 문서 안에서 JSX 컴포넌트를 사용할 수 있게 해주는 포맷입니다.

```tsx
// MDX 파일 안에서 React 컴포넌트 사용 가능
import { CustomChart } from './components/Chart'

# 나의 분석 결과

아래 차트를 확인하세요:

<CustomChart data={analysisData} />
```

## 코드 하이라이팅

`rehype-pretty-code`와 `shiki`를 사용하면 아름다운 코드 하이라이팅을 적용할 수 있습니다.

```typescript
interface Post {
  slug: string;
  title: string;
  date: string;
  content: string;
}

function getAllPosts(): Post[] {
  const files = fs.readdirSync(postsDirectory);
  return files
    .filter(file => file.endsWith('.mdx'))
    .map(file => parsePost(file));
}
```

## 다크모드

`next-themes` 라이브러리를 사용하면 시스템 설정에 따른 자동 테마 전환과 수동 토글을 쉽게 구현할 수 있습니다.

```tsx
const { theme, setTheme } = useTheme();

// 토글
setTheme(theme === 'dark' ? 'light' : 'dark');
```

## 정리

Next.js와 MDX의 조합은 개발 블로그를 만들기에 최적의 선택입니다. 정적 사이트 생성(SSG)으로 빠른 성능을 제공하면서도, React 컴포넌트의 유연함을 활용할 수 있습니다.

> 좋은 블로그는 꾸준한 글쓰기에서 시작됩니다.
